# VibeCheck brand assets

Neighborhood Patch is the selected VibeCheck signature. Three unequal regions
remain individually visible inside one Hearth Orange field: community as a warm
place made from distinct people, not a generic crowd icon.

## Files

- `logo.svg` — primary full-color square mark on Oat.
- `logo-mark.svg` — tightly cropped transparent mark.
- `logo-monochrome.svg` — Ink-only alternative with Oat separation.
- `favicon.svg` and `favicon.ico` — small-size browser assets.
- `wordmark.svg` — primary symbol-and-name lockup.
- `app-icon-*.png` — native vector rasterizations for app and Telegram use.
- `logo.png` — 512px full-color web export.

## Usage

Keep clear space equal to one internal seam width around the cropped mark. Use
the full-color mark on Oat or another light neutral. Use the monochrome mark when
production is limited to one ink. Do not recolor individual regions, add effects,
or rearrange the internal patch.

The wordmark lockup expects DM Sans and falls back to Avenir Next or the system
sans-serif. Convert the text to outlines before sending artwork to a printer or
another environment where those fonts are unavailable.

All PNG exports are native rasterizations of the SVG source. No generated image,
upscaling, external model output, or palette approximation is present.
